指令文檔

General

一般功能

  • /ping：回傳機器人目前的 WebSocket 延遲（ms）。
  • /choice options:<文字>：輸入以空格分隔的選項，機器人隨機選一個。
  • /quotes：顯示「名言」或「笑話」按鈕，點擊後取得對應內容。
  • /steal emoji:<emoji 字串或引用>：從 Discord 表情符號 CDN 下載並新增為本伺服器自訂 emoji；支援多個 emoji 一次處理，超過檔案大小上限會發送文字提示。
Weather

天氣查詢

  • /weather city:<縣市>：查詢台澎金馬地區各縣市的即時天氣資訊，資料由中央氣象署提供。
Bus

公車資訊

  • /bus：查詢台澎金馬地區各縣市的即時公車到站資訊，資料由交通部 TDX API 提供。
Server Info

伺服器資訊

  • /server_info：顯示目前伺服器的名稱、ID、成員數、建立時間、身份組數等詳細資訊。
Welcome

歡迎訊息

  • /welcome_active welcome_channel:<頻道> [rules_channel] [role_channel]：啟用歡迎訊息，設定歡迎頻道（必填）、規則頻道與身份組頻道（選填）。需「管理伺服器」權限。
  • /welcome_inactive：停用本伺服器歡迎訊息功能。需「管理伺服器」權限。
Music

語音功能

  • /music_join：加入使用者目前所在的語音頻道。
  • /music_leave：離開語音頻道並清空播放佇列。
  • /music_play query:<關鍵字或網址>：搜尋並播放音樂；若有歌曲正在播放則排入 FIFO 佇列。支援 YouTube／SoundCloud 關鍵字或直接貼網址。
  • /music_play_next query:<關鍵字或網址>：插播，插入佇列最前面，下一首優先播放。
  • /music_queue：顯示正在播放的歌曲與接下來最多 10 首的佇列清單。
  • /music_queue_clear：清空播放佇列（不影響正在播放的歌曲）。
  • /music_node_status：查看 Lavalink 節點連線狀態（URI、Session ID、連線伺服器數），僅使用者可見。
