隱私權政策

Data Collection

一、我們蒐集的資料範圍

  • 為了提供完整且穩定的 Discord 機器人與網頁控制面板功能，炙彗JI器人僅在功能運作所必需的最小範圍內處理及儲存以下資料：
    • 伺服器基本識別與設定資料：伺服器 ID（Guild ID）、頻道 ID（Channel ID）、身分組 ID（Role ID）、訊息 ID（Message ID），以及管理員自行設定的歡迎／離開訊息範本、專屬點歌頻道、表符身分組配對與關鍵字自動回覆規則。
    • 經濟系統資料：使用者的 Discord User ID、虛擬金幣餘額、每日／每小時簽到時間戳記與連續簽到天數。
    • 網頁控制面板登入資訊（OAuth2）：當您透過 Discord OAuth2 登入網頁控制面板時，系統會透過官方授權讀取您的基本公開檔案（User ID、顯示名稱、頭像）與所屬伺服器權限清單（identify、guilds），僅用於驗證您是否具備「管理伺服器」權限。
Message Content

二、訊息內容與語音資料處理原則

  • 一般聊天訊息：本機器人僅在比對伺服器設定之「關鍵字自動回覆」或執行指令時即時讀取訊息內容，不會將任何一般聊天對話紀錄寫入或保存於資料庫中。
  • 文字轉語音（TTS）與音樂播放：/tts 指令產生之語音暫存檔於播放完畢或離開語音頻道後即自動清理，本機器人不會對語音頻道內之任何使用者進行錄音或監聽。
Data Security

三、資料儲存、保護與第三方分享

  • 所有伺服器配置與經濟系統資料皆儲存於受保護的資料庫中，網頁控制面板採用 HttpOnly Session Cookie 與嚴格的伺服器管理權限校驗，防止未授權人員存取其他伺服器設定。
  • 我們絕不會將您的個人或伺服器資料出售、出租或交換予任何第三方行銷機構。僅在您主動觸發特定外部功能（如使用 /shorten 傳送待縮短網址至 reurl.cc API，或使用 /weather、/bus 查詢公開資訊）時，才會將該次指令所需之參數傳遞予對應服務。
User Rights

四、資料修改、清除與您的權利

  • 伺服器設定清除：伺服器管理員可隨時透過 Discord 指令（如 /welcome_clear、/music_channel_clear、/auto_reply_remove、/reaction_roles_edit）或登入「網頁控制面板」點擊各分頁的「清除設定」按鈕，立即從資料庫中永久刪除該伺服器的對應設定。
  • 政策更新：本隱私權政策可能隨功能迭代而修訂，更新後將直接公告於本頁面。最後更新日期：2026 年 10 月。
