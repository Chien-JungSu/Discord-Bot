機器人狀態：在線中

炙彗JI器人

這是一個於高中自主學習製作的多功能 Discord 機器人，整合了娛樂、天氣查詢、公車到站、伺服器資訊、歡迎訊息與語音功能。 目前機器人使用雲端貓居託管，24/7全天候上線。

加入官方支援群 GitHub Repository 邀請機器人
General

一般功能

  • /ping：測試機器人延遲
  • /choice：幫你從多個選項中做決定
  • /quotes：隨機名言與笑話互動功能
Weather

天氣查詢

  • /weather：查詢台灣各縣市的即時天氣
  • 支援中文與英文地名輸入
  • 提供溫度、降雨機率、舒適度資訊
Bus

公車資訊

  • 查詢城市公車路線到站時間
  • 顯示站牌資訊與車牌狀態
  • 提供路線與方向選擇
Server Info

伺服器資訊

  • /server_info：顯示伺服器基本資料
  • 可查看成員數與建立時間
  • 適合用於管理與社群資訊展示
Welcome

歡迎訊息

  • /active_welcome：設定加入歡迎頻道
  • /inactive_welcome：停用歡迎訊息
  • 新成員加入時自動發送歡迎卡片
Music

語音功能

  • /join：讓機器人加入語音頻道
  • /leave：讓機器人離開語音頻道
  • 未來可擴充音樂播放與自動播放功能
