模組介紹

General

一般功能

提供延遲測試、隨機抽選、名言笑話與表情偷取等日常娛樂指令

Weather

天氣查詢

整合中央氣象署 API，支援台澎金馬中英文地名即時天氣查詢。

Bus

公車資訊

串接交通部 TDX API，下拉選站查詢各縣市公車即時到站時間。

Server Info

伺服器資訊

一鍵顯示伺服器基本資料，包含成員數、建立時間等詳細資訊。

Welcome

歡迎訊息

新成員加入時自動發送歡迎 Embed，支援規則頻道與身份組頻道連結設定。

Reaction Roles

表符身份組

成員按表符即自動獲得或收回身份組，亂按的無效表符會自動移除。

Auto Reply

關鍵字自動回覆

成員訊息包含關鍵字時自動引用回覆，支援多組關鍵字與隨機回覆。

Music

語音功能

透過 Lavalink 播放 YouTube／SoundCloud 音樂，支援佇列、插播與節點監控。

TTS

文字轉語音

運用 Google 文字轉語音 (gTTS) 技術將文字轉成 MP3 檔案，支援自訂檔名與語言。

Shortener

短網址產生器

串接 reurl.cc API 將長網址縮短，支援自訂 UTM 追蹤標籤與一鍵跳轉按鈕。

Economy

經濟系統

全域互通錢包，提供每日／每小時簽到、富豪排行榜、轉帳與拉霸機、21點、刮刮樂等多款小遊戲。
